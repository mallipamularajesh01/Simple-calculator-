🧮 Simple Calculator (Python Basics)
This is a simple Python calculator program created to practice basic Python programming concepts.
The project is designed for beginners and helps in understanding how functions, loops, and condition statements work together in a real program.
📌 About the Project
The calculator allows the user to perform multiple mathematical operations such as:
Addition
Subtraction
Multiplication
Division
The program runs continuously until the user chooses to exit.
🛠️ Concepts Used
This project uses the following Python basics:
Functions (used as methods for calculations)
Conditional statements (if, elif, else)
Iteration using while loop
User input using input()
Arithmetic operators
Control flow using break
🧠 How It Works
The program defines separate functions for each operation.
A menu is displayed to the user.
The user selects an operation.
Two numbers are taken as input.
Based on the selected option, the corresponding function is executed.
The result is displayed.
The program repeats until the exit option is selected.
